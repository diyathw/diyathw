# Diyath Wickramaratne Portfolio

A production-ready personal portfolio for Diyath Wickramaratne, Senior Software Engineer.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static production output is written to `dist/` and can be deployed directly to Amazon S3 behind CloudFront.

## Content

Portfolio content and external profile links are centralized in `src/data/portfolio.ts`.
